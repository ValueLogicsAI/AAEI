## PORTABLE LOGIC SECTION

### What "portable logic" means

Most AI-generated platforms are brittle.
The business rules, pricing logic, compliance constraints,
and workflow definitions live inside thousands of lines of
implementation code — invisible, undocumented, and at risk
every time the platform is updated, migrated, or regenerated.

ValueLogics extracts the logic from the code.
We express it as a canonical value contract.
We fingerprint it with a Value Logic Hash.
And we prove it survived — every regeneration, every migration,
every platform change — with a board-shareable cryptographic proof.

**The code changes. The logic does not.**

## VLH SECTION (for the CTO / governance audience)

### The Value Logic Hash

When you regenerate a platform — new framework, new cloud,
new architecture — the files change completely.

How do you know the business logic survived?

The Value Logic Hash answers that question.

VLH is a SHA-256 fingerprint of the business logic contract —
not the files, but the meaning. The rules, metrics, workflows,
API contracts, and proof requirements that define what the
platform is supposed to do.

Before regeneration: VLH = `a3f9e2c1...`
After regeneration: VLH = `a3f9e2c1...`

Match. Every rule preserved. Every metric intact.
Every proof obligation carried forward.

If the hash does not match, the system reports exactly
what changed — and blocks the regeneration until
the change is authorized.

**A normal hash says: these files did not change.**
**The VLH says: this business logic did not change.**

## AAEI STANDARDS SECTION

### Open Standard — Proposed to OMG

AAEI is the AI Accountability Evidence Interchange standard.
AAEI v1.2 is a proposed OMG standard; Letters of Intent identify it for submission.

AAEI v1.2 defines 12 public fields for AI accountability evidence,
including two bridge fields to the OMG Business Motivation Model (BMM).

Energy reduction, token cost reduction, LDR and the Value Logic Hash
are not AAEI v1.2 fields. They are separate draft portable-logic /
LDR / VLH work.
